# EMB – Ets Mamadou Barboza

Application mobile e-commerce pour EMB à Dakar.

## Stack
- Expo / React Native
- Expo Router
- Node.js / Express backend pour PayTech
- FCFA
- Android + iOS

## Paiement
Les secrets PayTech doivent rester uniquement côté serveur. Ne mets jamais `API_SECRET` dans l'application mobile.

## Démarrage
```bash
npm install
npx expo start
```

Le dossier `backend/` contient l'API de paiement à déployer séparément.
